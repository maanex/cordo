# Contributing to cordo

First off, thank you for considering contributing to cordo! It's people like you that make open source such a great community.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue on [the issue tracker](https://github.com/Maanex/cordo/issues). Include as much detail as possible:
* Steps to reproduce the bug
* Expected behavior
* Actual behavior
* Versions of your runtime, your package manager, and cordo

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. When you are creating an enhancement issue, please provide:
* A clear and descriptive title
* A detailed description of the proposed feature
* Examples of how it would be used

### Submitting Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints (`npm run lint`).
6. Issue that pull request!

## Local Development Setup

To set up the project locally:

1. Clone the repository: `git clone https://github.com/Maanex/cordo.git`
2. Navigate to the project directory: `cd cordo`
3. Install dependencies: `bun install`
4. Build the project: `bun run build`
5. Run the linter to verify formatting: `bun run lint`

## Code Style
We use ESLint for our code. Please ensure your code passes the linter before submitting a pull request.

Thank you for contributing!
