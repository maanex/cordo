# Type Generation (`types/cordo.ts`)

## What it is

The Cordo Typegen file is an auto-generated TypeScript declaration file that provides absolute type safety for your routing logic. It defines a union type containing every valid route string in your application.

## How it works

When `Cordo.mountCordo()` is called, Cordo scans your `routes` directory to build its internal routing tree. If you have configured a `paths.types` destination in your `cordo.config.ts`, Cordo will write a TypeScript module declaration file to that location containing all the discovered routes.

```ts
// cordo.config.ts
export default defineCordoConfig({
  paths: {
    types: './src/types/cordo.ts' // Enables type generation
  }
})
```

## What it can do

The generated file augments the `cordo` module, specifically targeting the `DynamicTypes` interface.

```ts
// src/types/cordo.ts (Autogenerated)
declare module "cordo" {
  export type DynamicTypes = {
    Route: `command/help` | `command/settings` | `settings/${string}/notifications`
  }
}
```

This ensures that whenever you use a Cordo routing function (like `goto()` or `run()`), your IDE will provide autocomplete for all valid routes. It will also throw a TypeScript compilation error if you attempt to navigate to a route that doesn't exist, eliminating entire classes of runtime errors.

```ts
import { goto } from 'cordo/functions'

// ✅ Works perfectly, gives autocomplete
button().onClick(goto('command/settings'))

// ❌ TypeScript Error: Type '"command/missing"' is not assignable to type 'DynamicTypes["Route"]'
button().onClick(goto('command/missing')) 
```
