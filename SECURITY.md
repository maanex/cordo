# Security Policy

## Supported Versions

We take security seriously. Currently, we provide security updates for the following versions of cordo:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within cordo, please do not disclose it publicly.

Instead, please send an email to the project maintainer(s) directly or use GitHub's private vulnerability reporting feature. You can reach the author at: **cordo@maanex.me**.

Please include the following information in your report:
* The type of vulnerability.
* The steps required to reproduce the vulnerability.
* Any potential impact.

We will endeavor to respond to your report as quickly as possible, and will keep you informed of our progress towards a fix. Once the issue is resolved, we will publish a security advisory and a patched release.
